# AI Object Detection Project 

##Project Structure
- `main.py`: The entry point to start the training.
- `trainer.py`: Contains training and validation loops.
- `model.py`: Defines the Faster R-CNN model with ResNet50/MobileNet backbones.
- `dataset.py`: Custom PyTorch Dataset for loading images and YOLO labels.
- `args.py`: Configuration for hyperparameters (LR, Batch Size, Epochs).
